# Ограничения локальной практики

Версия 1, 13.11.2026. Первичный учебный документ.

## Среда
Локальный стенд использует Python 3.10+, без сторонних зависимостей. Для заданий на генерацию графики доступен вариант со сборкой из вложенных элементов.

## Сбои
Каталог имеет 50 записей, 20 из них ноутбуки. Третью страницу можно сделать временно недоступной параметром fail=1. Частичный набор нельзя считать полным.
