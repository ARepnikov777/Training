Создайте локальное приложение. Поля задачи/заявки: id (уникальный), title (1–100 символов после trim), description (текст), status (новая/в работе/готово). Создание со статусом новая; редактирование названия/описания и любого из трёх статусов; фильтр по статусу. Сохраняйте данные локально между перезагрузками и запусками. Удаление не требуется. Добавьте поиск по части title без учёта регистра, импорт и экспорт CSV UTF-8: id,title,description,status. Повторный импорт существующего id обновляет запись. Плохие строки не принимаются, но не мешают хорошим; ошибки содержат номер CSV-строки (заголовок = 1). Разрешены только три статуса. Автоматизация через браузер не обязательна, проверьте заданные сценарии.
