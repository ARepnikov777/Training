# [H12] Иллюстрированная инструкция

## Что сделать

Напиши иллюстрированное руководство на 4–6 страниц: как скачать комплект, сохранить исходники, выполнить и проверить задание. Проверь руководство на другом слушателе или независимом агенте.

## Как начать

Распакуй ZIP в отдельную папку. Прочитай все файлы .md/.json в input: они задают точные правила, ограничения и входные значения. Работай в отдельной рабочей папке, результат сохрани в result. Контрольные файлы checks можно использовать для самопроверки: это эталоны данных, не готовое решение. CSV: UTF-8, разделитель запятая, десятичная точка; в Excel используйте импорт «Из текста/CSV» с этими параметрами.

Независимая работа означает отдельного слушателя или отдельный процесс/сессию агента с ограниченным поручением; не имитируй её вторым ответом того же диалога. Субагенты либо второй локальный процесс доступны через используемый на курсе харнес; платная отдельная API-подписка не требуется.

## Что сдать

Готовый результат, исходники/промпты при наличии, инструкцию открытия/запуска и краткие доказательства проверки. Для программных дефектов — падение регрессионного теста до исправления и прохождение после. Для документов/графики — визуальная проверка. Готовые решения заданий не включены.

## Ограничения

Данные специально созданы для курса; это не реальные персональные, финансовые или коммерческие сведения. Все исходники доступны в этом комплекте; искать дополнительные материалы у преподавателя не нужно. Работа только на своём компьютере, без SSH, удалённых серверов и облачного развёртывания. Не перезаписывай выданные исходники.
