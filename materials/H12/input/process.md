# Процесс для руководства

Аудитория: слушатель, впервые скачавший учебный комплект.
1. Скачай ZIP задания из issue.
2. Распакуй в новую папку.
3. Прочитай README и input/rules.md или input/SPEC.md.
4. Скопируй исходники в отдельную рабочую папку.
5. Выполни задание, сохрани результат отдельно от исходников.
6. Проверь результат по checks и запиши способ повторения.

Сделай руководство на 4–6 страниц с редактируемым текстом и собственными иллюстрациями шагов. Используй элементы из elements.svg или доступный генератор. Не добавляй SSH, облачный сервер и требование купить программу. Для пользовательского прогона передай руководство другому слушателю, сохрани замечания. Если в момент самостоятельной работы другого человека нет, допускается независимый агент в отдельной сессии с чистой копией пакета; этот способ явно укажи в отчёте, не называя его человеческой проверкой.
