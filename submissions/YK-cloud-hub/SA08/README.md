Приоритет документа не назначен. Это проверка согласованности учебного комплекта, не юридическое заключение.

## Открытие и повторение

CSV: UTF-8, разделитель запятая, десятичная точка. В Excel используйте импорт «Из текста/CSV». Markdown открывается в редакторе или просмотрщике GitHub. PDF в source/H05/input/ — исходные документы, одна страница каждый; контрольные рендеры находятся в evidence/*.pdf.png.

1. Сверить SHA-256 source/H05.zip с evidence/input-hashes.json: `shasum -a 256 source/H05.zip`. Ожидание: `ba5c0e717a09b5414a93276e68ed85b2f9d7613b32ad7051a5e403d174f25b03`.
2. Прочитать source/H05/README.md, contract.md, workflow.md и брифы. Все записи ограничены этой папкой; исходники не менять.
3. Открыть три PDF. На macOS извлечь текст через Swift PDFKit (`PDFDocument`, `PDFPage.string`), для визуальной проверки — Quick Look: `qlmanage -t -s 1200 -o /tmp source/H05/input/*.pdf`. Новые пакеты для извлечения не устанавливались.
4. Сопоставить 11 полей каждого extractions/*.csv с точными цитатами в evidence/*-verification.md и страницами PDF. NOT_STATED означает отсутствие условия на проверенной странице.
5. Повторить сопоставление по contract.md. Первую версию сохранить отдельно, затем открыть source/H05/checks/expected.json. История первого результата — evidence/first-result/.
6. Проверить выводы и вопросы по реальным документам, получить независимое ревью. Отрицательный сценарий и его результат фиксируются отдельно в evidence/negative-scenario/.

Все данные синтетические. Контрольные ответы открыты координатором только после первого результата. Установленные типы explorer, worker и reviewer запускаются через нативный Codex с текущим входом ChatGPT; API-ключи и внешние CLI-исполнители не использованы.

## Предметные критерии

- Контрольные расхождения: quantity, total_price, delivery_date, ram, warranty — отдельные строки матрицы и F01–F05.
- Точные ссылки: source_file/page/quote в extractions; в матрице и реестре указаны файл, страница 1 и дословные фрагменты; отсутствие явно обозначено.
- Разделение: F01–F05 — противоречия; F06–F08 — неопределённости. В частности, «НДС не указан» не означает «НДС исключён»; включение настройки совместимо с несогласованным объёмом.
- Рекомендации: questions-to-supplier.md связывает вопросы с ID и документами для единой редакции; правильная сумма/конфигурация не выбрана за заказчика, юридических выводов нет.
