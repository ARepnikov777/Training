# Gitleaks — проверка и разбор исторической находки

Использован Gitleaks CLI 8.30.1 с --redact. Значения возможных секретов не публикуются.

Стандартная проверка общей локальной истории Git вернула **exit 1**, одну находку generic-api-key в materials/H09/checksums.json:3, исходный commit 22aad84cc6666d2b0abca011e95a96b12e69c9cd. Она относится к исходным материалам Training и существовала до решения.

Координатор прочитал JSON из этого commit, нашёл запись checks/key-points.md и независимо вычислил SHA-256 соответствующего файла из того же commit. Значение записи имеет формат 64 hex и **точно совпадает с вычисленным SHA-256**. Поэтому это подтверждённая контрольная сумма учебного файла, а не API-ключ.

Сканер не отключался; исключения, allowlist, подавление exit code и переписывание истории не применялись. **Полная автоматическая проверка не объявляется зелёной**: сохранён её код 1, отдельно приведена предметная проверка ложного срабатывания. Перед разрешённым push стандартный скан должен быть повторён на окончательной истории.

Изменения самого решения проверяются отдельно после формирования индекса командой gitleaks git --staged --redact .; скан требуется повторять после изменения индекса. Фактический результат последней проверки записывается в отчёте координатора/коммита. Никаких настоящих секретов для упражнений не создавалось.
