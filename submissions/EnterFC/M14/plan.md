# M14 — план проверки

Цель: проверить все восемь сценариев формы и сдать наблюдаемые доказательства, не исправляя учебные дефекты.

Запись: только `submissions/EnterFC/M14/`, исходники `kit/M14/` неизменяемы.

1. Прочитать issue в evidence/issue.json, README, input/START.md, input/scenarios.md. Проверить хеши входов.
2. Запустить локальный стенд на свободном loopback-порту. Использовать Orca browser по навыку orca-cli.
3. Сценарии 1–6: каждый с перезагрузкой и отдельными тестовыми данными. Сценарий 7: повтор успешной отправки тем же token без перезагрузки. Сценарий 8: в новой форме сначала пустое имя, затем исправление без перезагрузки.
4. Сохранить матрицу входов, ожидаемого и фактического результата для всех восьми сценариев. Для успехов и отказов записать фактический ответ, ошибки, id/token и screenshots; использовать только синтетические данные.
5. После сохранения первого отчёта свериться с checks/known-defects.md. Два класса намеренных ошибок не исправлять. Для каждого дефекта — воспроизводимые шаги и evidence.
6. Сохранить README со всеми четырьмя DoD, инструкциями повторения, результатами и ограничениями. Остановить только свой сервер после проверок.

Готовность: проверены все восемь сценариев, есть доказательства успехов и дефектов, исходники сохранены. Исправление формы, глобальные изменения и публикация исполнителем запрещены.
