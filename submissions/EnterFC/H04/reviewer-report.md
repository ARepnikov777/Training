## Ограничения и замечания

Полный batch reviewer заново не запускал: проверены существующие прогоны и выполнены настоящие OCR-тесты. RED содержит ожидаемые AssertionError, GREEN подтверждён текущим прогоном. Порядок «raw до checks» независимо доказать только по сохранённым файлам невозможно.

Защита результата от перезаписи реализована mkdir(exist_ok=False) до обработки; CLI возвращает 1 при повреждённом PDF. OCR-коррекции отдельно от raw, неопределённость A/А явно сохранена.

Неблокирующая особенность Ruff: команда README из каталога H04 проходит, но тот же бинарь из корня с полными относительными путями даёт I001 для импортов test_batch.py из-за классификации по рабочему каталогу. Ограниченный контракт прямоугольной сетки и поворота PDF описан; произвольные документы не заявляются поддержанными.
