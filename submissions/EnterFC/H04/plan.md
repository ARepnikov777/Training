# H04 — план обработки PDF

Цель: воспроизводимо обработать четыре PDF, извлечь текст/таблицу с привязкой к страницам, пережить повреждённый файл и явно перечислить места ручной сверки.

Запись: только `submissions/EnterFC/H04/`, исходный комплект `kit/H04/` неизменяемый. Данные только локальные, без SSH и платных API.

1. Прочитать issue, README и метаданные комплекта. Открыть исходные PDF, инвентаризировать страницы и выбрать реальное извлечение: текстовый слой, OCR скана, нормализация повёрнутой таблицы.
2. До кода написать поведенческие тесты пакетной обработки: текстовый документ, растровая страница, повёрнутая таблица, повреждённый вход и продолжение обработки остальных, корректные ссылки на страницы. Подтвердить RED по отсутствующему поведению, не из-за зависимостей.
3. Реализовать минимальный локальный пакетный скрипт с явными результатами/ошибками по документу и странице. Запустить GREEN. Зависимости закрепить; node_modules/venv/кэши не включать.
4. Выполнить первичное извлечение, сохранить неизменённый текст/OCR и изображения страниц в evidence. Только после этого читать checks/expected.md.
5. Сверить каждый контрольный фрагмент/число и таблицу с исходным изображением. Сохранить raw отдельно от исправленного результата, указать коррекции и неопределённости. CSV — UTF-8, запятая, десятичная точка.
6. Передать результат, страницу/ячейку ручной проверки, отчёт о непригодном файле, README со всеми пятью DoD и команды чистого повторного запуска. Координатор проверяет итог и публикует.

Готовность: все пригодные документы обработаны, повреждённый вход явно отражён, происхождение каждой страницы/таблицы сохранено, нет выдуманного OCR и неподтверждённых чисел. Нельзя подменять распознавание копированием checks.
