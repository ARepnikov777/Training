# Инструкция для визуального извлечения

Фактически применённый метод: Codex просмотрел три PNG-изображения страниц
через инструмент просмотра изображений и перенёс значения в CSV.
Ниже записано содержание рабочей инструкции для повторения; это не полный лог чата.

> Прочитай изображения трёх страниц scan.pdf. Сохрани названия ведомостей,
> пять заголовков, все значения и пустые ячейки строк A101–A104 и ИТОГО.
> Не вычисляй невидимые значения и не используй checks для первоначального
> заполнения. Сохрани первичную транскрипцию. Для неразборчивой ячейки укажи
> страницу, строку и столбец. Передай три CSV в UTF-8 с запятой как разделителем.
> Затем повторно сверь каждую ячейку по изображению, пересчитай произведения
> и общие итоги и только после этого сравни с checks/expected.json.
