# План M04

Цель: перенести три таблицы из scan.pdf в CSV с сохранением структуры и единиц.

Выбран CSV: три файла page-1.csv, page-2.csv, page-3.csv; XLSX — допустимая, но избыточная альтернатива для этих таблиц.

1. Проверить SHA-256 ZIP и распаковать его во временную папку.
2. Отрисовать три страницы, прочитать их визуально; сохранить первичную транскрипцию до чтения checks.
3. Повторно сверить все ячейки, заголовки, единицы, порядок A101–A104 и ИТОГО.
4. Открыть checks, пересчитать количества и суммы средствами стандартной библиотеки Python, записать фактические проверки.
5. Передать CSV, изображения страниц, журнал сомнительных ячеек, инструкцию и доказательства всех пунктов DoD.

Область записи: только submissions/ARepnikov777/M04/. Исходники неизменны. Публикация не входит в локальное выполнение.
