# SA09 — «Заявки практикума»

Задание: [#60](https://github.com/ARepnikov777/Training/issues/60) (предметная основа — [#39 H03](https://github.com/ARepnikov777/Training/issues/39)). Исполнитель: `zekayessss`.

Локальное приложение для координатора учебного центра «Вектор»: карточки заявок, поиск, фильтр по статусу, редактирование, сохранение между запусками, импорт и экспорт CSV с ошибками по номерам строк.

## Запуск

Нужен Python **3.10+**, сторонние пакеты не нужны. (На машине автора `python3` = 3.9, поэтому в командах ниже `python3.12`; подставьте свой интерпретатор 3.10+.)

```bash
cd submissions/zekayessss/SA09
python3.12 app/server.py                 # http://127.0.0.1:8000/
python3.12 app/server.py --port 8765 --data /tmp/sa09-clean/tasks.json   # другой порт и чистое хранилище
```

Откройте в браузере адрес из строки `Сервер запущен: …`. Остановка — Ctrl+C.

## Где хранятся данные

JSON-файл `data/tasks.json` рядом с приложением (`submissions/zekayessss/SA09/data/tasks.json`, в git не попадает). Другой путь — флаг `--data`. Запись атомарная (временный файл + `os.replace`). Несуществующий путь = пустое хранилище; повреждённый файл — сервер не стартует и не перезаписывает его.

## Инструкция координатора

1. **Создать заявку** — форма «Новая заявка»: название (обязательно, до 100 символов) и описание → «Создать». Статус ставится «новая», id выдаётся автоматически (`C0001`, …).
2. **Изменить** — «Изменить» в строке: название, описание, статус («новая» / «в работе» / «готово») → «Сохранить».
3. **Найти** — поле поиска по части названия (регистр не важен); **фильтр** — выпадающий список статусов, «Все» снимает фильтр.
4. **Импорт CSV** — выберите файл `id,title,description,status` (UTF-8) → «Импортировать». Отдельно показываются «Принято: N (создано X, обновлено Y)» и ошибки «Строка N (id …): причина» (заголовок = строка 1). Существующий id обновляется, а не дублируется; плохие строки не мешают хорошим.
5. **Экспорт CSV** — ссылка «Экспорт CSV» скачивает все заявки `tasks.csv` в той же схеме.

## Процесс (субагенты)

- **Граф:** [`workflow.md`](workflow.md) — составлен и проверен `graph_check.py` до запуска; там же типы субагентов, пределы (N=2 круга исправлений, T=3 ч, параллелизм 2).
- **Журнал:** [`run-log.md`](run-log.md) — каждое состояние, наблюдение, переход, счётчики.

- **Контракт** (результат T1): [`contract.md`](contract.md).
- **Ревью** (T5): [`review.md`](review.md).

**Инструмент:** Claude Code (модель Opus 5.5), а не Codex из условия — решение слушателя, принятое до запуска. Типы: `explorer` → `Explore` (только чтение), `worker` → `general-purpose`, `reviewer` → `Plan` (чтение и команды, без записи файлов). Самопроверка worker не считалась ревью: каждый результат worker перепроверен координатором (команды в `run-log.md`), финальную проверку делал отдельный reviewer.

**Отклонение от графа по факту запуска:** в таблице `workflow.md` для worker указан `isolation: worktree`. Первый запуск T2/T3 так и шёл, но автоматический worktree Claude Code создаётся от `main` основного checkout, и контракта в нём не было — оба worker остановились без изменений. Это прошло по ветке `impl_ok [иначе] → Live_check → Parallel_impl` (worker_retries 0→1); на повторе координатор создал явные worktree `sa09-wt/{storage,ui,scenarios}` от интеграционной ветки. Ветки: `student/zekayessss/SA09-storage`, `-ui`, `-scenarios`, интеграционная — `student/zekayessss/SA09`.

## Известные ограничения

- Python 3.10+ обязателен (в коде `:=` и `str | None`).
- Сквозные тесты не проверяют пустые строки внутри CSV — это покрыто только unit-тестом (`run-log.md`, 15:37: ошибочная мутация пропуска пустых строк e2e не поймал).
- UI в браузере проверен reviewer (Playwright, Chromium — `review.md`, U2); автоматических браузерных тестов в репозитории нет (по условию H03 не обязательны).
- Номер строки в ошибке импорта — номер записи CSV (заголовок = 1). Если выше есть поле в кавычках с переводом строки, номер меньше физической строки файла (`review.md`, замечание 1; в выданных файлах таких полей нет).
- После импорта принятые записи показаны числом «Принято: N (создано X, обновлено Y)», без перечня id; таблица сразу обновляется (`review.md`, замечание 2).
- Сервер однопоточный, рассчитан на одного координатора на своём компьютере.
