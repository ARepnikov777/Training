## Что сделать
Одна страница на русском для координатора «Заявки практикума»:
- таблица карточек (id, название, описание, статус);
- поиск по названию и фильтр статуса («Все» / «новая» / «в работе» / «готово»), список перезапрашивается `GET /api/tasks?q=…&status=…`;
- форма создания (название, описание) → `POST /api/tasks`; ошибка из `{"error"}` показывается рядом с формой;
- редактирование названия, описания и статуса существующей карточки → `PATCH /api/tasks/<id>` (id через `encodeURIComponent`);
- импорт: выбор файла + кнопка → `fetch('/api/import', {method:'POST', headers:{'Content-Type':'text/csv'}, body: file})`; результат показывает **отдельно** «Принято: N (создано X, обновлено Y)» и список «Строка <line> (id <id>): <error>»; ошибка файла (400) показывается текстом;
- ссылка «Экспорт CSV» на `/api/export`;
- пользовательские данные только через `textContent`/`createElement`, без `innerHTML` (РК-20);
- после любого изменения/импорта список перезапрашивается с текущими q и status.

Подключение ресурсов: `/static/app.js`, `/static/style.css`. Простой аккуратный вид, читаемо на узком экране.
