## Замечания

1. **Некритично. Нумерация строк при многострочном поле в CSV.** Шаги: импортировать CSV, где в строке X6 есть поле в кавычках с переводом строки, а следующая строка X7 ошибочная. Ожидалось: однозначный номер «CSV-строки». Получено: X7 помечена строкой 8. Это номер записи CSV, а физически X7 стоит на 9-й строке файла. В требованиях не сказано, что именно считать строкой, а в выданных файлах многострочных полей нет. Файл: `app/store.py`, `import_csv`, `enumerate(csv.reader(...), start=1)`.
2. **Некритично. Принятые записи в UI показаны только числом.** После импорта выводится «Принято: N (создано X, обновлено Y)», а id принятых записей не перечислены, хотя в ответе API (`accepted[]`) они есть. Отделение принятых от ошибок при этом выполнено: отдельный абзац и отдельный список «Ошибки строк», а таблица сразу обновляется. Файл: `app/static/app.js`, обработчик `import-form`.
3. **Некритично. `HEAD /api/export` возвращает 501.** Команда `curl -I`. Для пользователя это не важно: браузер скачивает файл через GET. Файл: `app/server.py`, `do_HEAD` нет.
4. **Некритично. README ссылается на `review.md`, которого в коммите нет.** Его должен создать координатор из этого отчёта. Файл: `README.md`, таблица доказательств и раздел «Процесс».
5. **Некритично. Нет favicon.** В консоли браузера 404 на `/favicon.ico`.
