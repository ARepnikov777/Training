## Что сделано

На странице `/shop` локального стенда исправлены три дефекта: игнорирование скидки, принятие пустого количества и неверная ссылка «Контакты». Правки минимальные, затронуты 2 файла, новых возможностей нет. `config.json` не менялся и по-прежнему содержит `"mode": "shop-buggy"`: по условию ошибки устраняются в коде, а не переключением режима.

| Путь | Содержимое |

Использованные инструменты: Claude Code (Opus 5.5) как агент под контролем слушателя, Python 3.12 (стенд и `unittest`), Node.js 26.13 (выполнение `app.js` вне браузера), curl, git.

## Дефекты до исправления (воспроизведены и описаны до правок)

Воспроизведение: `evidence/before.txt` (тесты на выданном коде) и `evidence/live-http.txt`, раздел «ДО».

| # | Сценарий из `checks/scenarios.md` | Ожидается | Фактически до исправления | Причина |
|---|---|---|---|---|
| 1 | Цена 1000, количество 3, скидка 10 | `2700.00` | `3000.00` | `app.js`: при `mode = shop-buggy` множитель скидки заменён на `1` (`buggy ? 1 : 1 - discount / 100`) |
| 2 | Пустое количество | ошибка, без числового итога | `0.00` | `app.js`: при `shop-buggy` вся проверка полей пропускается (`if (!buggy && …)`), а `Number('')` равно 0. Так же проходили цена < 0 (`-3.00`), количество 0, −2 и 2.5 (`0.00`, `-2000.00`, `2500.00`), скидка −1 и 101, нечисловая цена (`NaN`), пустые цена и скидка |
| 3 | Ссылка «Контакты» на `/shop` | `/contacts`, контактная страница | `/missing`, HTTP 404 | `serve.py`: в разметке `/shop` указано `href="/missing"`, хотя маршрут `/contacts` существует |

Попутное наблюдение: соседний сценарий «100×2, скидка 100 → 0.00» в исходнике тоже давал `200.00` из-за дефекта 1. После исправления он даёт ожидаемый `0.00`.

## Исправление

См. `evidence/fix.diff`:
- `result/site/app.js`: из обработчика `/shop` убрана зависимость от режима `shop-buggy`. Проверка полей по правилам `input/requirements.md` и формула `price*quantity*(1-discount/100)` с `toFixed(2)` теперь работают всегда. Существующая логика проверки и текст ошибки не менялись.
- `result/site/serve.py`: ссылка «Контакты» на `/shop` ведёт на `/contacts`.

## Как запустить и проверить

Нужны Python 3.10+ и Node.js 18+ (Node нужен только для теста калькулятора). Сторонних пакетов нет. Все команды выполняются из папки `submissions/zekayessss/M15/`.

Стенд:

```bash
python3 result/site/serve.py --port 8765
# открыть http://127.0.0.1:8765/shop; остановка — Ctrl+C
```

Проверки:

```bash
sh tests/run_all.sh                                   # «после»: исправленный result/site, код выхода 0
sh tests/run_all.sh ../../../materials/M15/input/site # «до»: выданный исходник, код выхода 1
```

Можно запускать и по отдельности: `node tests/test_shop.js result/site`, `python3 tests/test_server.py result/site`. Серверный тест копирует сайт во временную папку, поэтому `_state.json` в решении не появляется.

Ручная проверка в браузере на `/shop`: ввести 1000 / 3 / 10 → «2700.00»; очистить «Количество» → «Ошибка: проверьте цену, количество и скидку»; ссылка «Контакты» открывает страницу «Контакты».
