# M08 — план-факт бюджета

Готовый результат — `budget_plan_fact.xlsx`. Это редактируемая книга с тремя
листами:

- `План-факт` — формулы, общий итог, условное выделение и диаграмма;
- `План` — редактируемые плановые суммы;
- `Факт` — редактируемые операции.

Жёлтый фон отмечает входные ячейки. Сводные значения рассчитываются формулами
`SUMIF`, `SUM`, `факт − план` и `IF(план=0; "нет базы"; отклонение/план)`.

## Как открыть

Открыть `budget_plan_fact.xlsx` в Microsoft Excel или LibreOffice Calc. Изменить
числа на листах `План` или `Факт`: сводная таблица, итоги, подсветка и
диаграмма пересчитаются автоматически. Если в приложении отключён автопересчёт,
его нужно включить.

## Воспроизводимая сборка и проверка

Исходные CSV, правила и эталон скопированы без изменений в `source/`; их SHA-256
проверяются скриптом. Сохранённые уточнения issue находятся в
`source/issue-29-requirements.md`.

```bash
cd submissions/zhangir11/M08
go mod download
go run ./cmd/build
go run ./cmd/verify
```

Нужны Go 1.24+, LibreOffice Calc (`soffice`) и Poppler (`pdftoppm`). Вся логика
сборки и проверки написана на Go; Python-скриптов и Python-зависимостей нет.
`go run ./cmd/verify` проверяет формулы, значения, условное форматирование, ссылки
диаграммы, выполняет реальный пересчёт в LibreOffice и создаёт `evidence/preview.png` и
`evidence/verification.txt`.

## Definition of Done

- [x] **[Input] План, факт и отклонения рассчитаны по всем категориям и в общем итоге.**
  Факт: все 4 категории из объединения плана и факта включены. Итоги:
  план 220 000 KZT, факт 235 000 KZT, отклонение +15 000 KZT. Доказательство:
  `evidence/verification.txt`, проверки `category ...` и `total ...`; `evidence/preview.png`.

- [x] **[Input] Превышения выделены по заданному правилу; нулевой план обработан без ошибки деления.**
  Факт: строки с отклонением `> 0` выделяются красным; для «Транспорт»
  с нулевым планом формула возвращает «нет базы». Доказательство: `evidence/verification.txt`,
  проверки `zero-plan ...`, `conditional ...` и `highlight ...`; `evidence/preview.png`.

- [x] **[Input] Диаграмма соответствует значениям и единицам таблицы.**
  Факт: горизонтальная столбчатая диаграмма сравнивает план и факт по всем 4 категориям; ось и
  легенда указывают KZT. Доказательство: `evidence/verification.txt`, проверки `one category chart ...`,
  `chart contains ...`, `chart categories ...` и `chart series ...`; визуальная сверка в
  `evidence/preview.png`.

- [x] **[Input] Изменение исходных чисел обновляет формулы и диаграмму без ручной правки итогов.**
  Факт: в копии книги план «Площадка» изменён с 140 000 на 150 000 KZT. LibreOffice
  пересчитал категорию до `план 150 000 / отклонение 0`, а итог — до
  `план 230 000 / отклонение 5 000`, без ручной правки свода. Диаграмма ссылается на
  те же формульные диапазоны `B5:B8` и `C5:C8`. Доказательство: `evidence/verification.txt`,
  проверки `changing source ...` и `the same edit ...`.

## Инструменты и ограничения

Использованы Go 1.27.4, Excelize 2.10.0, LibreOffice Calc 24.2.7.2 и Poppler
`pdftoppm`. Результат визуально проверен по первому листу в `evidence/preview.png`:
таблица читается, подсветка видна, подписи диаграммы не обрезаны.

Ограничение по условию: категории сформированы из объединения выданных плана и факта.
Изменение чисел динамично; добавление совершенно новой категории требует пересборки
книги скриптом, что не входило в DoD.
