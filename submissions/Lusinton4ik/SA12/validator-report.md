# Отчёт валидатора SA12

Реализован независимый CLI `validate.py`: JSON-массив или CSV сверяется с каталогом и ожидаемыми ID; проверяются 50 записей и уникальных ID, десять полей и локальный HTTP(S) URL продукта. Результат — JSON с `ok`, `count`, `unique_count`, `errors`; код 0 при полном совпадении, 1 при расхождениях или ошибке чтения. Для CSV числа сравниваются через Decimal без округления. Импорт collector отсутствует.

Допущение о форме expected IDs: массив, объект с ключом `ids` (массив), либо объект, ключи которого являются ID. Для URL локальный стенд означает `localhost` или loopback IP. Реальный формат и фактический результат не проверялись по условиям задания; координатору требуется выполнить сверку и при необходимости адаптировать допущения.

Проверка в PowerShell из корня worktree (Python 3.12.10, UTF-8):

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
& 'C:/Users/lyudm/AppData/Local/Temp/sa12-python-3.12.10/python.exe' -X utf8 -m unittest discover -s submissions/Lusinton4ik/SA12/tests -p test_validate.py -v
```

До реализации — поведенческий RED: 8 тестов, 13 отказов на заглушке, не ошибка импорта. После реализации — 8 тестов, OK, код 0. Фактические команды и полный вывод обеих фаз: [evidence/validator-tests.txt](evidence/validator-tests.txt). Проверки используют только синтетические данные; содержимое collector и реальные catalog/checks не читались. Коммит, push и внешние действия не выполнялись.

## Уточнение nullable полей

В `availability`, `ram_GB`, `ssd_GB`, `screen_inches` допускается null только при null в эталоне: JSON `null` или пустая CSV-ячейка. Отсутствующий ключ и подстановки отвергаются; в эталоне ключи обязательны, а null в остальных полях запрещён. Реальные catalog/checks и collector не читались в этом раунде.

Повторена команда unittest из раздела выше с захватом вывода через Python; точная команда и полный вывод фаз в [evidence/validator-tests.txt](evidence/validator-tests.txt). RED: 12 тестов, 9 отказов, код 1: прежняя проверка ошибочно отвергала null в эталоне. GREEN: 12 тестов, OK, код 0. Использованы синтетические fixtures; реальную интеграционную сверку выполняет координатор.
