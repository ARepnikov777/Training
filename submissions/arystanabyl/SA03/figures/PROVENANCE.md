# Происхождение иллюстраций fig-01…fig-06

Источник элементов: `materials/H12/input/elements.svg` (лицензия — `materials/H12/input/LICENSE.md`).
Элементы перенесены копией содержимого группы `<g>` с трансформацией `translate/scale`;
в SVG такие группы помечены атрибутом `data-src="<id>"`. У копий `folder` и `circle`
местами заменена заливка на цвет из той же палитры (белый, `#1d8794`) или задана прозрачность.
Всё остальное нарисовано заново простыми фигурами SVG (`rect`, `path`, `circle`, `text`).

AI-генератор изображений не использовался. SVG собраны вручную написанным скриптом
(параметры координат), без растровых вставок и внешних ссылок.

Общее для всех рисунков:
- холст `width="1600" height="900" viewBox="0 0 1600 900"`, фон `#f5f7fa`;
- палитра `#172b3a`, `#1d8794`, `#f1b34a`, `#7063a3` и белый; галочка «OK» — `#1d8794`;
- шрифт меток `Segoe UI, Arial, sans-serif` (блок команды на fig-06 — `Consolas, monospace`), кегль не менее 52 px;
- подписи «Рисунок N. …» на рисунки не ставились — их даёт вёрстка.

Изменения: круг 1 — R-1, R-3.

Экспорт PNG: headless Microsoft Edge,
`msedge.exe --headless=new --disable-gpu --hide-scrollbars --user-data-dir=<TEMP>\sa03-edge --window-size=1600,900 --screenshot=<png> file:///<svg>`.
Размер каждого PNG проверен через Pillow: 1600×900. Каждый PNG просмотрен визуально.
