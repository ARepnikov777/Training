## Как открыть и повторить

- Открыть руководство: `guide/guide.pdf` в любом просмотрщике PDF. Исходник — `guide/guide.html` в браузере.
- Пересобрать PDF и PNG страниц: команды в `guide/build.md` (headless Microsoft Edge и Python 3 с Pillow).
- Проверить граф: `python -I <скилл agent-behavior-graph>/scripts/graph_check.py workflow.md` → `OK`, код 0.
- Повторить прохождение: взять `guide/guide.pdf`, новую пустую папку и выполнить S1–S6 в Windows PowerShell 5.1.
  Сверить результат с `evidence/walkthrough-protocol.md`.
- Повторить процесс по графу: состояния, брифы и пределы — в `workflow.md` и `briefs/`, порядок фактических
  переходов — в `run-log.md` и `git log --first-parent student/arystanabyl/SA03`.
