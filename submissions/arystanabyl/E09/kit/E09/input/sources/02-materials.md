# Правила материалов

Версия 1, 10.11.2026. Первичный учебный документ.

## Комплекты
Каждое задание получает ZIP с инструкцией, входами и контрольными примерами. Исходники не перезаписываются. Результат сдаётся отдельными файлами. В персональных полях используются вымышленные данные.

## Формат
Отчёт: PDF плюс редактируемый исходник.
