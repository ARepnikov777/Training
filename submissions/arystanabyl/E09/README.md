## Результат

Откройте [таблицу ответов](result/answers.md) в просмотрщике Markdown. Установка зависимостей и запуск кода не требуются. В таблице пять вопросов, ответы, ссылки на файлы и разделы и подтверждающие цитаты. Стоимость аренды не определена; вымышленные данные не представлены как сведения о реальном курсе.

## Порядок работы и инструменты

Использованы Git, GitHub CLI (чтение задания), PowerShell (распаковка и SHA-256), Gitleaks CLI и Markdown. Субагенты и внешние источники для ответов не использовались.
