## Проверка в новой сессии

Как требует учебная инструкция, проверка в **новой** сессии, а не в текущей:

```
cd <корень репозитория>
claude -p --output-format json "Сначала перечисли, какие пользовательские типы субагентов тебе доступны среди explorer, worker, reviewer, docs_researcher. Затем запусти субагента с явным типом explorer. Поручи ему только прочитать README.md этого проекта, вернуть главный тезис и ссылку на строку. Не изменяйте файлы. Дождись ответа, сам проверь ссылку чтением этой строки и сообщи: тип запущенного субагента, его ответ, результат проверки ссылки."
```

Claude Code 2.1.325, код 0, session `9613bd4a-297e-4f9e-81f1-5d25eb23bfb0`, ходов 3, $0.28.

Ответ сессии:

**Доступные типы:** все четыре из списка есть: `explorer`, `worker`, `reviewer`, `docs_researcher`.

**Тип запущенного субагента:** `explorer`. Он прочитал только `README.md` и сделал один вызов Read.

**Ответ субагента:**
1. Главный тезис: README объясняет, как слушатель берёт одно из 45 учебных заданий и сдаёт его одним Pull Request из отдельной ветки в `main`. В PR должны быть README и доказательства проверки по каждому пункту DoD.
2. Ссылка: `README.md:57`. Цитата: «Все слушатели имеют право записи в этот репозиторий. Работайте в отдельной ветке и сдавайте **одно задание одним Pull Request в `main` этого же репозитория**. Fork не нужен. Напрямую в `main` результаты не отправляем.»

**Проверка ссылки:** я сам прочитал строки 50–61 в `README.md:57`. Строка 57 слово в слово совпадает с цитатой. Она стоит первой под заголовком «## Подготовка и сдача задания» (строка 55), так что ссылка верная. Число «45 заданий» и требования про DoD я отдельно не проверял, потому что они не входят в цитату.

Файлы не менялись.

## Что это доказывает и что нет

- Доказано: новая сессия видит все четыре роли и реально запустила `explorer`;
  ссылка `README.md:57` проверена чтением строки.
- Не доказано: работа ролей `worker`, `reviewer`, `docs_researcher` (их не
  запускали); запуск 1 SA07 выполнен встроенными типами `Explore`,
  `general-purpose`, `claude` до создания этих ролей и не перезапускался.
