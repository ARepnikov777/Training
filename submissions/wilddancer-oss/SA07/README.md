  импортом «Из текста/CSV» (UTF-8, запятая).

  `OK …`, код 0.

- Повторить распознавание: Python 3 с `faster-whisper` 1.2.1 и скачанной
  моделью `medium`, затем из корня репозитория
  `ASR_MODELS=<папка моделей> python submissions/wilddancer-oss/SA07/asr/transcribe.py materials/H06/input/meeting.mp3 <выходная папка>`
  (подробно в `asr/method.md`; на CPU около 7 минут).
