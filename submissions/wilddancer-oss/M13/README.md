# M13. Сбор каталога ноутбуков через браузер

Задание: [#34](https://github.com/ARepnikov777/Training/issues/34). Текст issue с уточнениями сохранён в [evidence/issue-34.md](evidence/issue-34.md).

## Что сделано

Через браузер собраны все 20 ноутбуков локального стенда со страниц 1 и 2 каталога `/catalog?category=laptop`. Для каждой записи открыта карточка товара `/product?id=...`, из неё взяты поля и ссылка-источник. Результат: [result/laptops.csv](result/laptops.csv).

## Инструменты

- Исходный комплект: `downloads/M13.zip`, SHA-256 сверен с issue (`214ced3f...729149`), распакован в отдельную временную папку.
- Стенд: `python3 input/site/serve.py --port 8765` (Python 3, без пакетов).
- Браузер: Chromium через Playwright MCP под управлением агента Claude Code (один агент, под контролем студента). Скриншоты сделаны им же.
- Сборщик: [source/collect.js](source/collect.js), функция для консоли браузера. Выполнена в открытой вкладке стенда.
- Проверка: [source/verify.py](source/verify.py) (стандартная библиотека Python).

## Фильтры и правила

- Фильтр: категория `laptop` (ссылка «Ноутбуки», адрес `/catalog?category=laptop`). Других фильтров нет.
- Пагинация: по 10 записей. Ссылки страниц берутся из блока `nav[aria-label="Страницы"]` на первой странице, а не задаются вручную. Найдено 2 страницы.
- Поля: `id,name,category,price,currency,supplier,availability,ram_GB,ssd_GB,screen_inches,source_url`, как в `input/selection.md`.
- Пропуски: карточка показывает отсутствующее значение как `None`. В CSV оно оставлено пустым. Такое значение одно: `availability` у P003.
- `source_url`: адрес карточки товара на стенде, например `http://127.0.0.1:8765/product?id=P001`.
- `catalog.json` и `checks/expected-ids.json` использованы только в `verify.py`, для проверки после сбора.
- CSV: UTF-8, разделитель запятая, десятичная точка.

## Как повторить сбор

1. Распаковать `M13.zip`, из папки `M13` запустить `python3 input/site/serve.py --port 8765`.
2. Открыть в браузере `http://127.0.0.1:8765/catalog?category=laptop`.
3. Открыть консоль разработчика, вставить функцию из `source/collect.js` и вызвать её: `await (/* текст функции */)()`. Результат содержит `count`, `pages`, `rows` и готовый текст `csv`.
4. Сохранить поле `csv` в `result/laptops.csv` (так было сделано из [evidence/collector-output.json](evidence/collector-output.json)).
5. Проверить: `python3 source/verify.py <путь-к-распакованной-папке-M13>` из папки решения.
6. Остановить стенд Ctrl+C. Файл `_state.json` при этом не создаётся: каталог только читается.

## Ограничения

- `source_url` указывает на локальный стенд и открывается только при запущенном `serve.py` на порту 8765.
- Сборщик читает страницы через `fetch` внутри открытой вкладки и разбирает их HTML. Переходы по страницам 1 и 2 и по пяти карточкам сделаны в браузере отдельно, это видно на скриншотах.
- Независимой проверки другим человеком не было. Перепроверку выполнил тот же агент (скрипт и ручной просмотр скриншотов).
