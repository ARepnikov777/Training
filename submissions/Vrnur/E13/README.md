1. Цена, валюта, комплектация, наличие, ссылка и время проверки есть для каждого предложения — см. CSV.
2. Различия и недоступные сведения отмечены: у Гаммы наличие `null`, не приравнено к отсутствию.
3. Подтверждение: скриншоты страниц из встроенного браузера Orca, сделанные во время проверки (12:57:30–12:57:31 +05:00).
