## Как повторить

Нужен Python 3 с Pillow и numpy (`pip install pillow numpy`, лучше в виртуальном окружении):

```
python src/build_cards.py input result      # собрать карточки
python src/measure_cards.py input result    # проверить их по условиям
python src/preview.py result result/evidence  # лист и увеличенные края
```

Метод: в исходниках ровно три «фоновых» цвета — фон `#e8dccc`, диагональные линии `#d9c8b2` и тень `#c5b399`. Предмет — все пиксели другого цвета; всё остальное (в том числе тень и фон внутри ручки кружки) удалено. Предмет масштабируется пропорционально так, чтобы большая сторона его видимого bounding box стала 900 px, и ставится центром bounding box в (600, 600). Цвета вне предмета перед увеличением заменяются ближайшим цветом предмета, поэтому на краях нет каймы старого фона. Нейросети и внешние сервисы не использовались.

## Доказательства по DoD

Измерения: `result/evidence/measurements.txt` (скрипт `src/measure_cards.py`, проверяет итоговые PNG, а не параметры сборки). Допуски из уточнения issue.

1. **Пять карточек с заданными размерами, фоном и полями.** Все 5 файлов 1200×1200, угловые пиксели ровно `#f5f7fa`. Наименьшее поле — 149 px (требование ≥ 100).
2. **Положение и масштаб.** Большая сторона видимого bounding box: 900 / 901 / 900 / 901 / 900 px (допуск 900±20). Центр bounding box отклоняется от (600, 600) не более чем на 0,5 px по каждой оси (допуск 20 px). Подробности — `result/mapping.csv`.
3. **Цвет, пропорции, детали; края при увеличении.**
   - Цвет: основная заливка каждого предмета в карточке равна заливке в исходнике (`#1d8794`, `#df9e3a`, `#5b5d9f`, `#b24e58`, `#385e48`).
   - Пропорции: отношение сторон bounding box отличается от исходного не более чем на 0,25 %.
   - Остатков цветов старого фона и тени в карточках нет (0 пикселей).
   - Детали на месте: ручка и её отверстие, карман и контур кармана рюкзака, корешок и надпись IDEAS, полоски и кружок на колонке. Края при 4-кратном увеличении: `result/evidence/zoom_*.png` — бежевой каймы нет. Мелкая «лесенка» на краях присутствует уже в исходниках, у которых нет сглаживания, и при увеличении в 1,6–1,8 раза остаётся заметной.
4. **Исходники сохранены, соответствие однозначно.** `input/product-N.png` ↔ `result/card-N.png` с тем же N; таблица — `result/mapping.csv`.

Проверка самой проверки: на копии карточек card-1 была намеренно сдвинута на 40 px и в неё добавлены пиксели цвета тени; `measure_cards.py` на этой копии даёт FAIL по центру, полям, пропорциям и остаткам фона. Эта копия в сдачу не входит.
