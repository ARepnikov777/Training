## Подход и порядок работы

Выбраны горизонтальные столбцы: длинные категории читаются без поворота текста, общая нулевая база позволяет проверить длины. Круговая диаграмма разрешена брифом, но сравнивать четыре длины проще. Все столбцы одного цвета, отдельная легенда не нужна: категории подписаны непосредственно у столбцов.

План: распаковать и проверить ZIP → сверить CSV и бриф → подготовить SVG → экспортировать PNG → проверить геометрию, числа, размер и читаемость → получить независимую сверку.

Инструменты: Python 3 (csv, XML, hashlib, struct), текстовый SVG, macOS Quick Look и sips для экспорта, view_image для визуальной проверки. Генерация изображений ИИ не использовалась. Программная логика продукта не добавлялась; результат — документ и изображение.

## Открытие и повторный экспорт

Откройте `result/infographic.png` в просмотрщике изображений. Целевой размер — 1600×900.

Для правки откройте SVG в редакторе. Для экспорта без установки зависимостей откройте копию утилиты `source/M12/input/rasterize.html` в браузере и выберите `result/infographic.svg`. Утилита из комплекта скачает `result.png` с заданными в SVG размерами 1600×900. SVG самодостаточен, внешние изображения и шрифты не загружает.

Фактический экспорт выполнен Quick Look через временный квадратный холст 1600×1600 с вертикальным сдвигом композиции на 350 px, затем центральной обрезкой sips до 1600×900. Это устранило обрезание, обнаруженное в первом экспорте; SVG результата сохранён с исходными размерами 1600×900. Итоговый PNG открыт и проверен после исправления.
