# T3: очистка

Реализована очистка CSV по контракту: валидация, дедупликация, конфликт id, исходный текст записи и баланс. Тесты охватывают H07 (8 = 4 + 1 + 3), неверные даты, категорию, суммы, пустой id, повторы и конфликт, число полей, заголовок, сломанный и отсутствующий файл, quoting и многострочную запись.

- Python 3.9.6, стандартная библиотека.
- Из каталога решения `python3 -m unittest discover -s tests -v`: RED, код 1. До реализации вызываемый каркас вернул пустой результат: AssertionError в H07 и прочих поведенческих проверках; многострочный тест также вызвал IndexError из-за пустого списка. Полный вывод: `cleaning-red.txt`.
- Та же команда после реализации и дополнительной проверки граничных случаев: GREEN, код 0, 5 тестов. Полный вывод: `cleaning-green.txt`.
- Интеграция с остальными частями и независимая проверка артефактов в этом worktree не выполнялись: они относятся к задачам координатора.

- После `ruff check --fix` и `ruff format` для двух файлов повторены проверки: Ruff check — код 0 (`cleaning-lint.txt`), unittest — код 0, 5 тестов (`cleaning-green.txt`). Изменения Ruff ограничены форматированием, импортами и заменой форматирования строк на f-строки.
