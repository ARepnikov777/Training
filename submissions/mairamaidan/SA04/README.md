# SA04 — расходы учебного центра «Вектор»

Python 3.9+, только стандартная библиотека. Команды выполняются из этой папки.

```sh
python3 -m src.pipeline --input input --output result
python3 -m src.verify --input input --output result --expected checks/expected.json
python3 -m unittest discover -s tests -v
```

Конвейер читает `input/nov-1.csv`, `input/nov-2.csv`, `input/rules.json`; перезаписывает `result/clean.csv`, `result/rejected.csv` и `result/report.md`. UTF-8 CSV содержит заголовки; в отклонениях сохранены имя источника, номер первой физической строки, исходная запись и причина. Ошибки ввода и записи дают ненулевой код. Отчёт выражает суммы в KZT, перечисляет файлы и баланс.

Дата должна быть реальной и иметь вид YYYY-MM-DD, сумма — конечным неотрицательным Decimal, категория — из правил. Проверка предшествует удалению полных повторов четырёх исходных полей; при конфликте id первая корректная запись сохраняется, последующая отклоняется. Пробелы и регистр не нормализуются. Повторный запуск заменяет результаты; проверка повторяемости есть в тестах. В H07: 8 исходных = 4 принятых + 1 повтор + 3 отклонённых, всего 1000 KZT: 500 еда, 200 транспорт, 300 канцелярия.

`src.verify` — независимая проверка именно фиксированного H07, не общий валидатор: она сверяет записи с исходными CSV, дефекты отклонений, баланс и отчёт с `checks/expected.json`. Исходный комплект — [H07](https://github.com/ARepnikov777/Training/issues/43), [архив](https://raw.githubusercontent.com/ARepnikov777/Training/22aad84cc6666d2b0abca011e95a96b12e69c9cd/downloads/H07.zip). Локальные входы сохранены в `input/`.

Предметные критерии: одна команда выпускает три файла (см. выше и `result/`); повтор проверен побайтно в `tests/test_pipeline.py`; ошибки, причины и баланс — `result/rejected.csv`, `result/report.md`; показатели сверены независимым verifier с `checks/expected.json`. Доказательства запуска и отрицательного сценария — `evidence/integration-report.md`.

[Веха SA04](https://github.com/ARepnikov777/Training/milestone/4): [#102](https://github.com/ARepnikov777/Training/issues/102), [#103](https://github.com/ARepnikov777/Training/issues/103), [#104](https://github.com/ARepnikov777/Training/issues/104), [#105](https://github.com/ARepnikov777/Training/issues/105), [#106](https://github.com/ARepnikov777/Training/issues/106), [#107](https://github.com/ARepnikov777/Training/issues/107).
