# Course task illustrations

Screenshots for the twelve top-level subagent exercises (SA01–SA12), captured on 2026-11-15. They explain the task objects and supplied inputs; they are not completed student submissions or new acceptance criteria.

SA12 shows the actual `/catalog` page of the H13 local training server. Other screenshots show existing input documents, tables, code, or images rendered for readability. No answer keys from `checks/` were used. PDF illustrations use the first page or an explicitly labeled fragment. SA10 shows the first ten original archive entries.

Sources are the public, pinned training packs at commit `22aad84cc6666d2b0abca011e95a96b12e69c9cd`. All records and products are synthetic. Source code is MIT; course texts/data/illustrations are CC0 1.0 under the repository LICENSE. H11 product images and H12 elements retain their original provenance; no third-party images or generated replacement artwork were added.
