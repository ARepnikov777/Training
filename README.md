# Материалы курса по агентной разработке

45 самостоятельных учебных комплектов. Все документы, люди, товары и числа синтетические. Никакие материалы от преподавателя дополнительно не требуются.

Для выполнения задания откройте его issue, скачайте ZIP по ссылке «Скачать комплект», распакуйте и прочитайте README внутри. Браузерные стенды работают локально на Python 3.10+ без дополнительных пакетов. Для создания изображений дан вариант без платного генератора. Эталонные данные находятся в checks; алгоритмы решений не выданы.

## Пересборка для организатора

Python 3.14, зависимости из requirements-build.txt, шрифт DejaVu Sans и libespeak-ng с русским голосом, ffmpeg. Команда: `python tools/build_materials.py`. Для слушателя пересборка не нужна: готовые PDF, PNG и MP3 включены. Проверка: `python -m pytest tests -q`, `ruff check tools tests`, `ruff format --check tools tests`. Намеренно неисправный код лежит только в учебных input/project и стендах mode=*-buggy; проверки самого комплекта должны проходить.
